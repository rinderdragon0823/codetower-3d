使い方

  1. GitHubリポジトリのURLを貼って「3D化」
  2. ドラッグで回転 / ホイールでズーム / 右ドラッグで移動
  3. ビルをクリック →「🧬 コードを立体化」で中身が3Dタワーに！
  4. 地区 = 先頭フォルダ / 高さ = ファイルサイズ / 色 = 拡張子
